**Azure Yachts** — это полноценное веб-приложение для продажи и бронирования элитных яхт. Проект реализован на стеке ASP.NET Core с использованием динамической базы данных, что позволяет управлять каталогом в реальном времени.

---

## 🌟 Особенности проекта

*   **Динамический каталог:** Данные о яхтах (название, цена, характеристики) не прописаны в коде, а загружаются из БД SQLite.
*   **Премиальный интерфейс:** 
    *   Интерактивный слайдер на главной (JS).
    *   Адаптивная сетка (Grid) с карточками товаров.
    *   Всплывающие окна (Pop-up) с детальными ТТХ моделей.
*   **Мобильная адаптивность:** Сайт полностью перестраивается под iPhone и другие смартфоны.
*   **Dev Tunnels:** Настроен запуск через туннели Visual Studio для доступа к сайту из интернета во время разработки.

---

## 🗄️ Архитектура базы данных (EF Core)

Логика базы данных построена на **Entity Framework Core** по принципу **Code-First**.

### 1. Модели (Models)
Классы C# автоматически превращаются в таблицы SQLite.
*   **Yacht** — данные о судне (Id, Name, Price, Capacity).
*   **Booking** — информация о бронированиях.
*   **User** — данные клиентов.

### 2. Управление данными (AppDbContext)
Центральный узел, который связывает C# и базу данных `azureyachts.db`. Позволяет выполнять CRUD-операции:
*   Добавление яхт (`Add`)
*   Обновление цен (`Update`)
*   Удаление и фильтрация (`LINQ`)

### 3. Связи (Relationships)
Реализованы связи через **Foreign Keys** (Внешние ключи). Например, таблица `Bookings` связана с `Yachts` через `YachtId`, что позволяет видеть, какое судно забронировано.

## 🖥️ Как запустить сайт

1.  **Открыть проект:** Запустите файл `.sln` в Visual Studio 2022.
2.  **Инициализировать БД:** Откройте консоль диспетчера пакетов и выполните:
    ```bash
    Update-Database
    ```
3.  **Настроить доступ:**
    *   В меню запуска выберите **Dev Tunnels**.
    *   Создайте публичный туннель (Public).
4.  **Запуск:** Нажмите **F5**. Сайт откроется по локальному адресу или через публичную ссылку туннеля.
