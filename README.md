# Praktika_IIT
🛥️ Azure Yachts — Full-Stack Web Solution
Azure Yachts — это высокотехнологичное веб-приложение на стеке ASP.NET Core, представляющее собой цифровую платформу для управления флотом элитных яхт. В основе проекта лежит мощная система обработки данных, реализованная по принципу Code-First.
Проект разработан в Visual Studio 2022 и настроен для работы в реальных условиях через Dev Tunnels.
#⸻
📌 Архитектура базы данных
Сердце приложения — реляционная база данных SQLite, работающая через ORM-прослойку Entity Framework Core. Разработка ведется на чистом C#, где программные классы автоматически трансформируются в таблицы БД.
🧠 Логика данных:
Модели (Models): Описывают структуру сущностей. Например, класс Yacht автоматически генерирует таблицу с полями Id (Primary Key), Name, Price и Capacity.
Контекст (AppDbContext): Центральный узел управления. Через DbSet приложение взаимодействует с таблицами как с коллекциями объектов, выполняя операции CRUD (создание, чтение, обновление, удаление) без написания чистого SQL-кода.
Связи (Relationships): Реализована сложная логика зависимостей. Например, сущность Booking (Бронирование) связана с Yacht и User через Внешние ключи (Foreign Keys) и навигационные свойства, что позволяет легко получать данные о том, какую яхту забронировал конкретный клиент.
#⸻
🧩 Основная функциональность
Динамическая витрина: Данные о яхтах подгружаются из SQLite и отображаются на фронтенде в реальном времени.
Система бронирования: Логика регистрации заявок на аренду с привязкой к конкретным моделям судов.
Управление данными (Admin Logic): Возможность программного изменения цен, описаний и состава флота через методы EF Core.
Dev Tunnel Launch: Поддержка запуска через туннели разработчика, что позволяет тестировать бэкенд на мобильных устройствах или демонстрировать работу заказчику по внешней ссылке.
⸻
🛠 Технологический стек
Framework: ASP.NET Core 8.0+ (MVC / Razor Pages)
Database: SQLite (легкая, быстрая, файловая БД)
ORM: Entity Framework Core (уровень абстракции над БД)
IDE: Visual Studio 2022
Frontend: Интерактивный UI (HTML5, CSS3 Grid, JavaScript)
Tunneling: Visual Studio Dev Tunnels

🚀 Инструкция по запуску (для разработчика)
Открыть файл решения .sln в Visual Studio.
Убедиться, что установлены NuGet-пакеты:
Microsoft.EntityFrameworkCore.Sqlite
Microsoft.EntityFrameworkCore.Tools
Выполнить миграции (если структура БД изменена):
dotnet ef migrations add InitialCreate
dotnet ef database update
Выбрать профиль запуска с включенным Dev Tunnels.
Запустить проект (F5). Приложение будет доступно по публичной ссылке.
