🛥️ Azure Yachts — Full-Stack Yacht Management System

C# .NET SQLite Visual Studio JavaScript

Azure Yachts — это высокотехнологичная веб-платформа для управления флотом
элитных яхт и обработки бронирований. Проект прошел путь от статического
лендинга до полноценного Full-Stack приложения с динамическим управлением
данными через СУБД.

🚀 Ключевые возможности

  - Динамический каталог: Информация о яхтах (цены, характеристики, фото)
    загружается напрямую из базы данных.
  - Интерактивный интерфейс:
      - Автоматический слайдер на главной странице (Vanilla JS).
      - Умные всплывающие окна (Pop-up) с ТТХ яхт, которые адаптируются к краям
        экрана.
  - Удаленный доступ: Настроен запуск через Visual Studio Dev Tunnels, что
    позволяет открывать проект по публичной ссылке для тестирования на
    смартфонах или демонстрации клиенту.
  - Полная адаптивность: Сайт оптимизирован под любые устройства — от
    широкоформатных мониторов до iPhone.

🗄️ Архитектура и База Данных

Логика данных построена на Entity Framework Core. Разработка ведется по принципу
Code-First — таблицы базы данных автоматически генерируются из C#-классов.

1. Модели (Models)

Каждая сущность — это класс. Например, класс Yacht содержит свойства Id, Name,
Price, Capacity. EF Core маппит их в типы SQL (INTEGER, TEXT, REAL).

2. Концент управления (AppDbContext)

Связующее звено между кодом и SQLite. Через него реализованы CRUD-операции:

  - context.Yachts.ToList() — получение всех судов.
  - context.Bookings.Add(newOrder) — создание новой заявки.

3. Связи (Relationships)

Реализованы связи между таблицами через Foreign Keys:

  - Yacht ↔ Booking: Связь "Один ко многим". Одно бронирование жестко привязано
    к конкретному ID яхты через навигационное свойство.

💻 Инструкция по запуску

1.  Клонирование: Откройте проект в Visual Studio 2022.
2.  База данных: Откройте Консоль диспетчера пакетов и примените миграции для
    создания БД:
    Update-Database
3.  Запуск через Туннель:
      - В Visual Studio в выпадающем меню кнопки "Пуск" выберите Dev Tunnels ->
        Create a Tunnel.
      - Установите тип доступа: Public.
      - Нажмите F5.
4.  Результат: Visual Studio выдаст временную публичную ссылку (например,
    https://random-id.devtunnels.ms), по которой ваш сайт будет доступен из
    интернета.

📂 Структура проекта

  - /Models — C# классы (Yacht, User, Booking).
  - /Data — Контекст базы данных (AppDbContext).
  - /wwwroot — Статические файлы (CSS, JS, изображения яхт).
  - /Views — Razor-шаблоны страниц каталога.
